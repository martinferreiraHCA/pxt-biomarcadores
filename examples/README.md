# Ejemplos

Programas listos para pegar en MakeCode (pestaña JavaScript o Python) después de agregar la
extensión, más una versión MicroPython independiente.

| Archivo | Qué hace |
|---|---|
| `latidos-led.ts` | El corazón de la matriz late con cada QRS; botón A muestra los BPM |
| `ecg-consola.ts` | Envía la señal filtrada, la energía y los BPM por USB para verlos en la consola/gráfico de MakeCode |
| `hrv-radio.ts` | Calcula una medida simple de variabilidad (HRV) y la manda por radio |
| `latidos-led.py` | Lo mismo que `latidos-led.ts`, en MakeCode Python |
| `micropython/ad8232.py` | Módulo MicroPython (editor python.microbit.org), sin MakeCode |
| `micropython/main.py` | Programa de ejemplo que usa el módulo |
